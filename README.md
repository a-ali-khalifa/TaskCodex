# Task Codex

Task Codex is a gamified task-management web application and open-source project designed to make productivity more engaging through interactive game mechanics. It aims to make organizing and completing tasks more enjoyable, especially for, but not limited to, people with ADD/ADHD.

## Features

- **Gamified productivity:** Turn everyday tasks into a more engaging experience through progression and game-inspired mechanics.
- **Leveling system:** Earn progress and level up as you complete tasks.
- **Ranks & progression:** Track your progress through ranks as you advance.
- **Achievements & rewards:** Celebrate your journey through messages and feedback when reaching milestones.
- **Sound effects:** Addictive audio feedback for certain interactions and progression events.
- **Task management:** Create, organize, and track tasks through an interactive dashboard.
- **Progress tracking:** Monitor task completion and overall progress.
- **Interactive interface:** A minimalist yet game-inspired UI designed to make everyday task management feel more rewarding.
- **Progress syncing:** Sync your data across various devices.
